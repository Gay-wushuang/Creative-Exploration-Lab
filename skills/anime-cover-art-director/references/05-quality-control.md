# 05 · QA：出图前 / 出图后

## 六维审查（每项 0–5）

| 维度 | 满分标准 | 常见失败 |
|---|---|---|
| 人设忠实度 | 发型、五官、配饰、服装对应原图 | 变脸、换装、眼色错误 |
| 文案准确度 | 名称、标题、数字、日期、奖励无错漏 | 漏字、改数字、错字 |
| 结构设计 | 元素有清晰主次，标题真正参与画面 | 左字右人、装饰堆叠 |
| 可读性 | 小图可读，标题和人物不互相吞噬 | 文字过小，背景太亮 |
| 主题表达 | 概念与标题/歌曲情绪直接相关 | 漫无目的的特效 |
| 绘制质量 | 手指、面部、头饰、遮挡和透视合理 | 多指、肢体融合、错位 |

高风险阻断项：人物身份认错；活动奖项/金额/日期错误；标题错字；用户禁止项出现；画面比例错误；明显肢体结构错误。即使整体美观也不能当成合格最终图。

## 出图前 checklist

- [ ] 当前用户动作是设计、出图、编辑还是审查？
- [ ] 人物图号/身份/台词归属正确？
- [ ] 已确认的方案中不可变项均已锁定？
- [ ] 精确文案已照抄并保持层级？
- [ ] 输出比例/人物占比/安全边界正确？
- [ ] 设计能解释“为什么这样构图”？
- [ ] 细节不会造成视觉噪声或替换原人设？

## 出图后 checklist

- [ ] 与原图对照发饰、发型、眼色、服装。
- [ ] 用肉眼逐字核对中文标题与活动信息；对不能确认的标出风险。
- [ ] 缩到直播间缩略图尺寸再看标题是否清晰。
- [ ] 手、头发交叉、玻璃倒影等是否合理。
- [ ] 是否加入了未允许的角色、道具、奖品或多余文字。
- [ ] 对上一个版本指定的局部更改是否生效；其他地方是否被无端改动。

## 用户反馈优先处理

- **太雷同**：主结构必须更换，不只是滤镜和配色。
- **太空**：扩大主标题、增加层次，不靠贴纸乱填。
- **人物不对**：回到原人设，对照面部、发饰、服装逐项修。
- **字错**：尽可能以准确字体层替换，不把重做当成唯一方案。
- **太浅/对比不足**：调整局部明度差、冷暖差及阅读层级，不一味提高饱和度。
