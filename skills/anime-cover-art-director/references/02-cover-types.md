# 02 · 封面类型策略

## A 直播间封面
- 展示优先级：角色脸 > 主标题 > 第二卖点 > 名称；信息最多 2–3 层，按平台缩略图判断。
- 典型 4:3，人物可放大到脸部特写；文字占据成块视觉空间，避免大面积空置。
- 可爱风不是必须堆粉色/爱心；用字体比例、非对称构图、对比与角色表情建立识别度。
- 例：“元气甜妹 全能歌势 / 新人第一天播播 / 番茄酱香”必须保持三层语义与准确文字。

## B 歌切封面
- 先确认用户提供的歌名和 Cover，允许只做概念不作歌词解释；涉及歌曲具体背景应核实。
- 情绪设计用一条主隐喻（如胶片人潮、温差玻璃、撕裂海报），不要多条互不关联隐喻同时出现。
- 人物可作设计中心，但不允许为了风格而改变辨识身份。
- 采用 4:3 时明确预留安全边界，标题不能陷入复杂花纹。
- 防止“一律左字右人”的固定公式。可以有字压脸旁、文字充当建筑结构、双重曝光等，但不牺牲可读性。

## C 投稿封面
- 先明确台词归属、笑点、双方关系，特别是多人角色的图号与“谁说什么”。
- 提倡大脸/大字对冲、漫画分镜、大小错位与层级；单图可以用放大的人物表情 + 反转标题。
- 若标题有歧义，喜剧来自语气与表情，不设计露骨暗示。
- 不要编造真实指控事实；设计表达不等于内容事实核验。

## D 活动/满月海报
- 信息一般按：标题/时间 → 大航海等级 → 榜单门槛 → 盲盒/惊喜 → 活动流程。可依篇幅调整。
- 所有门槛、数字、奖励、限定条件必须精准；无法一次排清，可以建议拆成封面图和详情图，但不能未经允许删内容。
- 对大量文字建议“先出无字底图，再用精确排版”以避免乱码；如果仅有图像生成工具，坦率告知长文准确性风险。
- 角色建议占整体显著比例，但不能挤占正文；标题醒目，栏目标题和说明形成阅读层级。

## 通用制作规格
- 标注比例时严守实际输出长宽，常见 4:3 / 16:9，别把纵版当横版。
- 上下、左右保留被平台裁切的余量；无用户指定时不承诺某个平台的具体安全区像素。
- 区分用户希望“封面只需标题”和“包含活动详情”的不同交付。
