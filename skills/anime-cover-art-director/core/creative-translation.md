# 创意转译 / Creative Translation
创意是可跨媒介的关系、规则、体验、问题或表达，不等于研究对象的外观。转译不是套模板，也不是必须画图。先保留原始创意，再选择目标成果的专业适配。
1. 抽取不可替代核心：原问题、发现、关系/规则、意图、体验；哪些是可变表现？如果改变媒介，什么必须留下？不必强行提炼唯一规则，允许直接作品或开放问题。
2. 形成映射：来源条件→目标的对应结构/行为/表达；明确哪些属性不迁移、哪些是比喻或假设。根据需要尝试多种转译，包括反向转译或混合媒介；不强制每案两次制作。
3. 在目标媒介恢复约束并形成可执行方案。静态图可用时间切片/结果痕迹等表现动态关系，但不能声称实际交互已实现；规则或体验设计需明确状态、输入输出、反馈、使用过程，而不止讲视觉隐喻；叙事关注事件/关系/感受。适用时使用专业格式。概念探索可保持开放，不必承诺最终成品。
4. 检验：即使不读解释，目标受众是否可能感受其核心？去掉研究对象装饰后关系仍成立吗？是否因转译改变事实或功能？核心损失是否可接受？必要时返回规则实验或原路径，不把失败掩饰成风格变化。成品阶段按 `../evaluation/reverse-translation.md` 从真实证据反查核心关系，并区分表达保真与机制实现。
5. 冻结执行时记录所选方案、核心关系、映射、必须保留的内容、交付规格、可变项、禁止项、尚待验证的假设。用户未确认的重大修改仅作建议。
例：研究声学共振→提取相互响应与增强关系→将其转译为文字间距与主体节奏，或交互反馈之间的耦合；不需要把声波画进去。示例不是预设模板。
