# 作品 ↔ 规则：双向创造
作品与规则不是互斥路线。允许直接构思、写作、绘制或构造作品；也允许先建立局部规则，运行实验，观察结果。已有作品可能暴露一个有价值的关系，抽象之后改变规则，再产生新的作品。偶然输出可反向改变问题和探索方向。
- 作品→规则：观察真实或假设作品，描述可观察结构/体验，提出多个可能解释，不把反向推断称为唯一生成原理。
- 规则→作品：设定状态、操作、条件、关系或反馈；在可用工具内运行小规模生成或模拟。观察实际样本、对照基线、改变参数，区分设计结果与意外涌现。
- 两者可切换、回溯或共同演化，不要求规则先于作品，也不要求所有任务程序化；简单直接创作同样有效。
- 涌现不是复杂性的同义词：仅在观察到由交互产生的结果时描述观察，未运行则为假设。不能靠复杂程度证明创新；保留出人意料但相关且可表达的发现。
- 退出：作品/规则已经提供独特且相关的表达或体验，进一步实验收益低，或触及预算；未知条件保留，不无限迭代。
临时实验记录用于本轮验证和交付，不构成长期规则库或视觉基因库。
