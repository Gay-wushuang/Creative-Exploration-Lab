# C · Transformation / 规则突破
起点为共同 brief + 对可变默认规则的质疑；不读取 A/B 候选作为出发点。找出隐含假设，区分用户硬约束与常规假设：可以是意义、系统、体验、因果、观察条件、表达或实现规则，不限视觉。提出反事实，例如反转、删除、替代、交换、极限化、重构；这些不是必选清单。根据假设按需联网查证或拓展，利用开放实验、规则生成、作品抽象、机制迁移或直接创作发现新关系。不要把虚构规律说成真实机制；必要时对照原规则和新规则。通过 `../core/creative-translation.md` 将核心变化转成目标成果，说明原规则、新规则/新问题及保留的功能。保持与其他候选实质差异。
